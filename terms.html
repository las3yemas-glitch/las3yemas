Términos de Servicio

Esta aplicación pertenece a Las 3 Yemas y se utiliza para gestionar y automatizar contenido en redes sociales.

El uso de la aplicación está destinado a usuarios autorizados por Las 3 Yemas.

La aplicación puede conectarse con servicios de terceros, incluido TikTok, para publicar contenido autorizado.

El uso de TikTok está sujeto también a los términos y políticas establecidos por TikTok.

Las 3 Yemas puede modificar estos términos cuando sea necesario para mantener el funcionamiento de sus servicios.

Contacto: Las 3 Yemas, Chile.
